# Rule-Based AI Chatbot 

## Project Overview
The Rule-Based AI Chatbot is a simple Python chatbot that interacts with users using predefined rules and conditions.

## Features
- Greeting responses
- Personalized interaction
- Time and date feature
- Joke feature
- Mood response system
- Exit command support

## Technologies Used
- Python
- VS Code

## How to Run
1. Install Python
2. Open terminal
3. Run:
   Rule-Based AI Chatbot.py

## Sample Output
You: hello
Bot: Hello! Nice to meet you.

You: bye
Bot: Goodbye!

## Conclusion
This project demonstrates the basics of Artificial Intelligence and chatbot development using Python.
